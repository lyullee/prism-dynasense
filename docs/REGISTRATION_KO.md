# 소프트웨어 저작권 등록 준비자료

## 프로그램 식별

| 항목 | 내용 |
|---|---|
| 제호 | PRISM-DynaSense |
| 버전 | 0.1.0 |
| 한글 기능명 | 사고 시간변화·민감도 분석 프로그램 |
| 형태 | Python 패키지, 명령행 실행기, 오프라인 HTML 결과 화면 |
| 목적 | 사고 조건의 변화가 시간별 결과와 불확실성에 미치는 영향 분석 |
| 적용 환경 | Python 3.12 이상, Windows 우선 확인; 결과는 현대 브라우저에서 열람 |
| 언어 | Python, JavaScript, HTML, CSS |
| 공개 저장소 | https://github.com/lyullee/prism-dynasense |

이 문서는 **등록 신청을 준비하기 위한 프로그램 설명**입니다. 등록증이나 법적 권리 귀속 확인서가 아닙니다. 실제 기관별 제출 형식과 제출할 소스 범위는 신청 시 확인해야 합니다.

## 프로그램의 구성과 특징

1. **입력 검사**: SI 단위 입력과 민감도 범위의 형식·물리적 경계 검사, 잘못된 물질·변수 거부
2. **사건 연결**: 유한 재고의 감압 누출, 점화, 상류 차단, 격리구간의 잔류 방출을 하나의 이력으로 계산
3. **외부 계산 연결**: 설치된 PRISM의 열노출·피해 변환 함수 연결, 버전·모듈 해시 저장
4. **분석 제어**: Sobol 표본마다 사고모델 직접 실행, 동일 사례 캐시, 국소 하한·상한 비교, 수렴·실패 판정
5. **결과 표현**: 실제 데이터에 기반한 한글 대시보드, 출력 선택, 시간대별 민감도 비교, CSV/JSON/그림 저장
6. **재현 관리**: 입력 해시·원본 소스 해시·패키지 버전·seed·표본 수준 기록

v0.1.0의 물리 시나리오는 가압 수소기체 누출과 열노출입니다. 다른 화학물질 전체, 확산·폭발, 현장 센서 실시간 연결, 설비 전체 위험성평가를 구현했다고 기재하지 않습니다.

## 원저작 부분과 외부 부분

등록 준비용 원본 소스에는 `src/prism_dynasense/`의 Python·대시보드·자체 예제와 자체 작성 테스트·도구를 구분해 담습니다. 소스 인벤토리는 파일명, 바이트 수, 줄 수, SHA-256을 포함합니다.

PRISM, SALib, NumPy, SciPy, Matplotlib, Pydantic은 외부 의존성입니다. 이들의 원본 소스를 새 프로그램의 독자 창작 부분으로 제출하지 않습니다. 수학식, Sobol 알고리즘 자체, 기존 PRISM의 열피해식에 대한 독점적인 신규 창작을 주장하지 않습니다. 신규 프로그램의 조합·실행 흐름·입력 처리·수렴 제어·결과 표시를 구체적으로 구분합니다. 세부 내용은 `ARCHITECTURE.md`와 `THIRD_PARTY_NOTICES.md`에 있습니다.

## 준비 묶음 생성

개발 환경에서 빌드와 테스트를 마친 뒤:

```console
python tools/build_registration_bundle.py
```

`artifacts/registration/`에 아래 파일을 만듭니다.

- `PRISM-DynaSense_0.1.0_registration-preparation.zip`: 소스 스냅샷·설명서·화면·설치물·실제 예제·검증 기록의 준비 묶음
- `source_inventory.json`: 프로그램·테스트·도구 파일별 분류와 SHA-256
- `release_manifest.json`: 묶음 안의 모든 파일에 대한 해시 목록
- `SHA256SUMS.txt`: 최종 묶음과 설치물의 무결성 확인값

묶음에는 가상환경, 인증정보, 개인 폴더 경로, 비공개 연구 원자료, 외부 논문 PDF, 외부 라이브러리 원본을 넣지 않습니다. 같은 소스에서 생성한 zip 파일도 생성 시각·파일 메타데이터 등에 따라 바이트가 달라질 수 있습니다. 파일별 SHA-256으로 포함 내용의 동일성을 확인합니다.
