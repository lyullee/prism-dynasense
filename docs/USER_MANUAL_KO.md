# PRISM-DynaSense v0.1.0 사용설명서

## 이 프로그램으로 답할 질문

“누출구가 커지거나 차단이 늦어지면 시간별 열노출이 어떻게 달라지는가?”, “우리가 정한 범위에서 어떤 조건이 결과를 가장 크게 바꾸는가?”에 답합니다. 사고의 발생빈도나 설비 전체의 안전등급을 판정하지는 않습니다.

## 설치와 첫 실행

Python 3.12 이상이 필요합니다. GitHub Releases에서 wheel을 내려받아 설치합니다. 인터넷은 의존성 설치 시 필요합니다. 설치가 끝나면 계산과 결과 열람은 로컬에서 수행합니다.

```console
python -m pip install prism_dynasense-0.1.0-py3-none-any.whl
prism-dynasense doctor
prism-dynasense demo --out result --open
```

`doctor`는 실제 설치된 PRISM 버전과 모듈 해시를 출력합니다. 버전이 0.6.8과 다르면 계산을 중단합니다. 모델 결과가 PRISM 업데이트 때문에 조용히 바뀌는 일을 막기 위한 처리입니다.

실행 명령을 찾지 못하면 `python -m prism_dynasense` 뒤에 같은 하위 명령을 붙여 실행합니다. `--open`은 결과 화면을 기본 브라우저로 여는 선택사항입니다.

## 입력 수정

```console
prism-dynasense template input.json
```

이 명령은 기존 파일을 덮어쓰지 않습니다. 생성한 JSON의 `scenario`는 기준 사례이고, `variables`는 민감도 분석에서 변화시킬 입력입니다. 입력은 모두 SI 단위이며 압력은 **절대압**입니다.

| 입력 키 | 의미·단위 | 기준값 | 허용 범위 또는 조건 |
|---|---|---:|---|
| fluid | 물질 | Hydrogen | 현재 Hydrogen만 지원 |
| initial_pressure_pa | 초기 절대압, Pa | 2,000,000 | 101,325 초과~5,000,000 |
| temperature_k | 온도, K | 293.15 | 250~350 |
| upstream_volume_m3 | 차단밸브 상류 연결 용적, m³ | 0.6 | 0 초과~1,000 |
| isolated_volume_m3 | 차단밸브 하류 누출구까지의 용적, m³ | 0.025 | 0 초과~100 |
| hole_diameter_m | 누출구 직경, m | 0.004 | 0 초과~0.05 |
| discharge_coefficient | 유출계수 | 0.8 | 0 초과~1 |
| isolation_time_s | 상류 차단 완료시각, s | 10 | 0 이상 |
| ignition_time_s | 점화시각, s | 1 | 0 이상 |
| receptor_distance_m | 점열원에서 평가 지점까지 거리, m | 1 | 0.5~1,000 |
| radiant_fraction | 방출 열량 중 복사 비율 | 0.1 | 0 초과~0.4 |
| atmospheric_transmissivity | 대기 통과 후 남는 복사 비율 | 0.9 | 0 초과~1 |
| horizon_s | 평가기간, s | 40 | 0 초과~3,600 |
| time_step_s | 출력 간격의 상한, s | 0.5 | 0 초과~평가기간 |

허용 범위는 프로그램 입력 검사 범위입니다. 전 범위에서 정확도가 검증되었다는 의미가 아닙니다. 작은 거리에서는 점열원 근사 자체가 부적절할 수 있습니다. 출력 간격 수는 20,000 이하여야 합니다. 점화·차단·평가시간 25/50/75% 시점은 출력 간격과 별도로 삽입합니다. 차단이 평가기간 뒤이면 해당 기록에서 차단이 일어나지 않습니다. 점화가 평가기간 뒤이면 열노출은 0입니다.

민감도 변수는 위 목록에서 평가기간·출력 간격·물질을 제외한 11개 중 선택합니다. 같은 변수는 중복할 수 없습니다. 기준값은 각 하한~상한 안에 있어야 합니다. 알 수 없는 키, 잘못된 단위의 범위 초과값, NaN/무한대 입력은 거부합니다.

## 계산 명령

기준 사례만 계산하려면:

```console
prism-dynasense run input.json --out baseline
```

민감도 분석을 함께 수행하려면:

```console
prism-dynasense sensitivity input.json --out study --levels 512 1024 2048 --resamples 300
```

`--levels`는 최소 두 단계의 증가하는 2의 거듭제곱이며 각 단계는 16~16,384입니다. `--resamples`는 Sobol 지수의 부트스트랩 반복 수로 최소 50입니다. 표본 생성 seed는 JSON에 저장합니다. 첫째 효과 S1과 총효과 ST를 계산하며 개별 2차 상호작용 지수 S2는 계산하지 않습니다.

5개 변수에서 N=2,048이면 한 단계 설계행은 2,048×(5+2)=14,336개입니다. 여러 단계의 동일 입력은 캐시로 재사용합니다. 서로 다른 표본의 사고모델은 실제로 다시 계산합니다. 샘플 일부를 빼거나 실패값을 0으로 채우지 않습니다. 실패하면 해당 출력 지수는 보류합니다.

동일 결과 폴더를 지정하면 그 안의 출력 파일을 갱신합니다. 다른 연구를 보관하려면 새 폴더를 지정합니다. 입력 JSON 원본을 고치는 명령은 아닙니다.

## 화면 읽기

위쪽 숫자와 시간 이력은 **기준 사례**입니다. Sobol 그림과 시간대별 주요 변수는 **입력 범위를 변화시킨 전체 표본**의 결과입니다. 두 종류의 결과를 혼동하지 않습니다.

- 누출률 그래프: 차단 후에도 남은 수소가 계속 나오는지 확인
- 열유속 그래프: 점화 전에는 0, 점화 이후에는 누출률과 함께 변화
- 누적 열노출: 순간 열유속이 내려가도 이미 받은 열노출은 줄어들지 않음
- 피해확률 그래프: 누적 열노출을 PRISM의 열피해식으로 환산한 조건부 값
- 출력 선택: 누출질량·최대 누출률·최대 열유속·최종 열노출·조건부 피해확률·중간 열노출 3개 중 선택
- Sobol 점: ST 추정값, 가로 선: 부트스트랩 95% 신뢰구간의 반폭

지수는 선언한 범위와 입력 분포에 따라 바뀝니다. ST가 크다고 그 변수를 같은 비율만큼 줄이면 피해가 그만큼 줄어든다는 뜻은 아닙니다. 실제 설비 간 발생빈도를 비교하는 순위도 아닙니다. 상호작용 때문에 ST의 합이 1을 넘을 수 있습니다. 표본 오차 때문에 S1이 음수이거나 ST가 1을 넘는 추정값도 숨기지 않습니다.

수렴 판정은 마지막 두 단계의 모든 입력을 비교합니다. ST 최대 변화 ≤0.05, ST 신뢰구간 최대 반폭 ≤0.10, 상위 3개 변수 집합 일치를 모두 만족하면 통과합니다. 변수 수가 3보다 적으면 있는 변수를 사용합니다. 통과는 **수치적 안정성 기준**이며 현장 정확도 인증이 아닙니다.

## 오류와 해석 보류

`WITHHELD`는 결과를 계산하지 않았다는 뜻과 다릅니다. 수렴 기준을 넘지 못하면 추정 그림은 보이되 보류로 표시합니다. `UNDEFINED_CONSTANT_OUTPUT`은 표본 내 출력이 모두 같아 분산 민감도를 정의할 수 없다는 뜻입니다. 점화 전 누적 열노출 0이 대표적입니다. 계산 실패 표본이 있으면 출력 지수는 추정하지 않으며 CLI는 종료코드 2를 반환합니다. 미수렴만으로 종료코드 2를 반환하지는 않습니다.
