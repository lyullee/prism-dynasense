# PRISM-DynaSense

**사고가 시간에 따라 어떻게 변하고, 어떤 조건이 피해를 좌우하는지 살펴보는 분석 프로그램**

PRISM의 열노출·피해확률 계산과 Sobol 민감도 분석을 연결했습니다. 계산 결과는 한글 대시보드, CSV, JSON, PNG, SVG로 제공합니다. 설치 후에는 개인 컴퓨터에서 계산합니다.

![실제 계산 대시보드](docs/screenshots/desktop.png)

## 핵심 기능

1. **시간에 따른 사고 계산**: 누출 시작, 점화, 상류 차단, 격리구간의 잔류 방출을 순서대로 반영
2. **PRISM 연결**: 설치된 PRISM 0.6.8의 열노출 적분과 열피해 변환 함수를 실제 호출
3. **민감도 분석**: 입력 범위를 함께 변화시키는 Sobol 분석과 변수 하나씩 변화시키는 국소 비교
4. **결과 신뢰도 표시**: 표본 증가에 따른 지수 변화·신뢰구간·상위 변수 집합 확인, 미수렴 결과 보류
5. **시각화와 내보내기**: 시간 이력, 출력별 민감도, 시간대별 주요 변수, 재현정보 제공

## 이번 버전의 계산 범위

v0.1.0의 실제 물리모델은 **가압 수소기체 누출·지연점화·상류 차단·열노출**입니다. 물질명만 바꾸어 암모니아 등 다른 물질에 적용할 수는 없습니다. 입력·분석·시각화 구조는 확장할 수 있지만 다른 물질의 물리모델은 별도로 구현하고 검증해야 합니다.

동적이라는 말은 압력·재고량·누출률과 사건 시점이 변한다는 뜻입니다. 확산이나 화염 형상을 시간에 따라 정밀하게 푸는 프로그램은 아닙니다. 복사는 점열원 근사를 사용합니다. 가까운 거리의 예시 결과로 실제 이격거리를 결정해서는 안 됩니다. 설비 전체의 연간 사고위험도는 계산하지 않습니다.

## 사용 순서

Python 3.12 이상 환경에서 [GitHub Releases](https://github.com/lyullee/prism-dynasense/releases)의 wheel 파일을 설치합니다.

```console
python -m pip install prism_dynasense-0.1.0-py3-none-any.whl
prism-dynasense doctor
prism-dynasense demo --out result --open
```

입력을 직접 바꾸려면 다음 명령으로 JSON을 만든 뒤 수정합니다.

```console
prism-dynasense template input.json
prism-dynasense sensitivity input.json --out result --levels 128 256 512
```

`report.html`은 실제 계산을 읽는 화면입니다. 화면에서 값을 바꿔 계산하는 편집기는 아닙니다. 새로운 조건은 JSON 수정 후 다시 계산합니다. 자세한 절차와 단위는 [한글 사용설명서](docs/USER_MANUAL_KO.md)에 있습니다.

## 결과 해석

- **누출질량**: 정한 평가시간 안에 나온 수소의 양
- **열유속**: 평가 지점에 순간적으로 도달하는 복사열의 세기
- **열노출량**: 열의 세기와 노출시간을 함께 반영한 누적량
- **조건부 피해확률**: 입력한 사고와 노출이 주어졌을 때 PRISM 열피해식으로 환산한 값
- **ST**: 정한 입력 범위 안에서 그 변수가 결과의 흔들림에 얼마나 관여하는지 나타내는 지수

ST는 사고빈도나 위험감소율이 아닙니다. 표본 수를 늘려도 지수가 불안정하면 보류합니다. 수렴했다고 실제 현장 피해를 검증한 것은 아닙니다.

소프트웨어 등록 준비자료에는 프로그램 설명·원본 소스 목록·파일 해시·설치 파일·화면 예시를 묶습니다. [등록 준비 안내](docs/REGISTRATION_KO.md)에서 원저작 부분과 외부 라이브러리의 구분을 확인할 수 있습니다. 실제 등록 신청과 권리자 확인은 별도입니다.
